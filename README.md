# Satzbuch

Workout-Tracker als PWA (Web-App fürs iPhone): unbegrenzte Routinen, Live-Workout mit Vorher-Werten,
Pausen-Timer, Scheiben-Rechner, Verlauf, Fortschritts-Diagramme, JSON-Backup. Alle Daten bleiben lokal
im Browser (IndexedDB), kein Konto, kein Tracking.

```bash
npm install
npm run dev      # Entwicklung
npm run build    # Produktions-Build nach dist/
```
